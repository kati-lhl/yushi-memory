# 仿生设计原则（只写概念，不写参数）

> 这是受生物记忆启发的设计说明，不是算法论文。  
> 具体阈值、打分、巩固条件、召回公式不在这里。

## 1. 痕迹，不是事实

生物记忆先留下弱痕迹，反复出现才变成稳定记忆。

对应结构：

```text
memory.jsonl       稳定事实
记忆痕迹.jsonl     弱痕迹
```

弱输入不直接进事实层。

## 2. 巩固

短时、重复、带情绪或带证据的信息，才值得长期保存。

原则：

```text
一次输入 ≠ 长期记忆
重复/纠正/明确教学 → 提高巩固优先级
```

## 3. 遗忘

不用会变冷，但不物理删除。

对应状态：

```text
active → cold
```

冷数据仍可找回，只是默认不参与召回。

## 4. 再巩固

每次被召回，记忆会被加强。

原则：

```text
召回不是只读
被用到的记忆 → 留存上升
```

## 5. 干扰与冲突

新事实和旧事实冲突时，不覆盖历史。

对应状态：

```text
旧记忆 → superseded
新记忆 → active
```

保留“她以前记成什么”。

## 6. 睡眠/离线整理

白天只记录，夜间再整理。

对应结构：

```text
日志/        白天事件
日记/        夜间总结
脑内独白/    主观层
记忆隔离区/  待审候选
```

## 7. 情境依赖

同一句话，在不同场景下意义不同。

对应字段：

```text
scene_scope
scene_tags
topic
```

召回时可以受场景影响。

## 8. 情绪只改权重

情绪影响“多容易想起”，不改变事实真假。

原则：

```text
情绪 → 权重
事实 → 事实
```

不能因为生气就改写用户说过的话。

## 9. 可审计

生物记忆会改写，但系统必须能解释。

对应结构：

```text
审计日志/
记忆变更.jsonl
source_quote
```

## 边界

这里只给设计语言和数据结构。  
不包含：

```text
遗忘曲线参数
召回打分公式
自动巩固阈值
冲突判定规则
```

这些属于实现策略，不开源。
